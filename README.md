# New API on Railway

[![Deploy on Railway](https://railway.com/button.svg)](https://railway.com/deploy/IfyGwd?referralCode=tcitry&utm_medium=integration&utm_source=template&utm_campaign=generic)

Choose **New Project** to deploy an independent New API instance with PostgreSQL and Redis. Railway pulls the three official images configured in the template.

[`template-config.json`](template-config.json) records the settings visible on the template's deployment page, including service sources, variable references, generated-secret expressions, volume mounts, and networking.

Railway deploys the settings saved in its template editor. After changing the template there, update the snapshot here so the changes can be reviewed in Git.
